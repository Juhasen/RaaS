# Agent Workspace Rules & Guidelines Map

Use this directory map to locate specific code style and technology guidelines depending on which microservice/directory you are working on.

## Guideline Directory Map

- **Go Microservices** (`/listing`, `/media`, `/booking`)
  - Read guidelines in: [guidelines/GO.md](guidelines/GO.md)

- **Java Microservices** (`/payment`, `/review`, `/favorites`)
  - Read guidelines in: [guidelines/JAVA.md](guidelines/JAVA.md)

- **Python Microservices** (`/notification`, `/user`, `/analytics`)
  - No guideline file yet; follow PEP 8 and match the surrounding code.

- **Frontend App** (`/ui`)
  - Read guidelines in: [guidelines/TYPESCRIPT.md](guidelines/TYPESCRIPT.md) and [guidelines/ANGULAR.md](guidelines/ANGULAR.md)

## General Instructions
Before modifying a service, read its guideline file above. The guidelines set the code style for that stack; follow them so the services stay consistent.
