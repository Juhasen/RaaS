# Data Model: API Gateway Entry Point & Auth Context

## Entities

### AccessTokenClaims
- user_id (string; from JWT subject claim)
- role (enum: host, guest)
- issuer (string)
- audience (string)
- expires_at (timestamp)

Validation:
- signature valid against configured keys
- exp not expired
- issuer and audience match configured values

### UserIdentityContext
- user_id (string)
- role (enum: host, guest)
- authenticated (boolean)
- request_id (string)

Validation:
- generated by gateway only
- never accepted from client input

### Route
- id (string)
- method (string)
- path_pattern (string)
- backend_service (string or base URL)
- public (boolean)
- required_roles (list<string>)
- ownership (OwnershipPolicy | null)

### OwnershipPolicy
- resource_type (string)
- resource_id_source (path parameter name)
- verifier_endpoint (string)
- timeout_ms (integer)

## Relationships

- Route -> OwnershipPolicy (optional, one-to-one)
- Route -> backend_service (required)
- UserIdentityContext is derived from AccessTokenClaims at the gateway
