# Quickstart: 008-frontend-init

## Prerequisites

- Node.js 20+ and npm

## Install

```bash
cd ui
npm install
```

## Run Dev Server

```bash
npm run start
```

Open `http://localhost:4200/`.

## Routes

- `/listing/create` - listing creation placeholder
- `/listing/manage` - listing management placeholder
- Unknown paths render the not found page

## Tests

```bash
npm run test
```
